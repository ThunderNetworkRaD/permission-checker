# Changelog

All notable changes to this project will be documented in this file.

## [4.1.1] - 2025-07-10

### Changed
- Deprecated version 4.1.0 due to critical issues
- Updated documentation to reflect deprecation

## [4.1.0] - 2025-07-10 (DEPRECATED - DO NOT USE)
**This version has been deprecated due to critical issues. Please upgrade to 4.1.1 or later.**

### Added
- New `replaces` option for dynamic permission values
- Support for parameterized permissions with placeholders
- Comprehensive documentation for all functions and interfaces
- TypeScript type definitions for all options

### Changed
- Improved documentation with detailed examples
- Better type safety with TypeScript generics
- Enhanced error messages for debugging
- Updated dependencies to their latest versions

### Fixed
- Fixed type definitions for better TypeScript support
- Resolved edge cases in permission matching
- Improved handling of special characters in permission strings

## [4.0.0] - 2025-07-09

### Added
- Full TypeScript support with type definitions
- Support for both ESM and CommonJS modules
- Browser compatibility
- Bun runtime support
- Comprehensive test suite
- Detailed documentation with examples
- CI/CD ready configuration

### Changed
- Complete rewrite of the permission checking logic
- Improved performance and reliability
- Better error handling
- Simplified API surface

### Removed
- Legacy code and deprecated APIs
- Unnecessary dependencies

## [3.0.0] - 2023-01-15

### Added
- Initial release of the permission checker
- Basic permission checking functionality
- Support for wildcard permissions
- Hierarchical permission checking

### Changed
- Improved performance
- Better documentation

## [2.0.0] - 2022-06-20

### Added
- Support for permission lists
- Better error messages
- More test cases

### Changed
- Updated dependencies
- Improved build process

## [1.0.0] - 2021-11-05

### Added
- Initial release
- Basic permission checking
- Simple API
